# 坦克大战 Tank Battle

一个纯 HTML + JavaScript 实现的经典坦克大战游戏（Battle City 风格），单文件即可运行，无需任何依赖。

## 玩法

- **移动**：`W` `A` `S` `D` 或方向键
- **射击**：`空格`
- **暂停**：`P`

守住底部中央的基地，消灭一波又一波敌人坦克。砖墙可以被子弹摧毁，钢墙无法破坏。基地一旦被毁则游戏结束，通关 3 波即获胜。

## 运行

直接用浏览器打开 `index.html` 即可，无需安装或构建。
